VT_Patcher  هي أداة متطورة لـ (Patcing)  تعديل ملفات APK
تم تطويرها بواسطة  𝓙𝓸𝓴𝓮𝓻丨𝓜4  🇪🇬

الوظائف المتاحة:
  ✅  باسورد VPN و SSL Bypass  (تخطي جميع أنواع الحماية)
  ✅  إزالة الإعلانات (Ads Removal)
  ✅  تزوير معلومات الجهاز (Random Device Info Spoof)
  ✅  تخطي حماية Flutter SSL
  ✅  تخطي حماية Pairip CoreX
  ✅  تثبيت Xposed/LSP Modules (Pine Hook)
  ✅  تعديل تطبيقات Telegram (مكافحة حذف الرسائل، بريميم، وغيرها)
  ✅  حقن AES Logs
  ✅  تخطي الشراء والدفع (Purchase/Premium Bypass)
  ✅  تخطي تصوير الشاشة (Screenshot Restriction Bypass)
  ✅  إزالة قيود USB Debugging
  ✅  دعم APKEditor و APKTool
  ✅  دمج ملفات .apks / .xapk / .apkm
  ✅  توقيع APK تلقائيًا (Auto Sign)

              📥  طريقة التثبيت (Termux)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

الطريقة الأولى - تثبيت مباشر (بأمر واحد):
────────────────────────────────────────
افتح Termux واكتب:

  pkg update -y && pkg install -y wget curl
  curl -L https://github.com/VT_YC/VT_Patcher/releases/latest/download/install.sh | bash

أو:

  wget -qO- https://github.com/VT_YC/VT_Patcher/releases/latest/download/install.sh | bash


الطريقة الثانية - تثبيت يدوي:
────────────────────────────────────────
 1.  حمّل الملف VT_Patcher.zip من قناة @VT_YC
 2.  انقله إلى مجلد الهوم:
       cp /sdcard/Download/VT_Patcher.zip ~/
 3.  فك الضغط:
       cd && unzip -o VT_Patcher.zip
 4.  شغل الأداة:
       cd VT_Patcher && bash start.sh -h

❖  الأمر الأساسي:
──────────────────
  vtpatcher -i مسار_التطبيق.apk

  أو:
  python3 VT_Patcher/APK_PATCHER.py -i مسار_التطبيق.apk

  أو:
  bash start.sh -i مسار_التطبيق.apk


❖  فلاج (علم) شهادة SSL:
────────────────────────
  -c  ➜  إضافة شهادة HTTPS (من HttpCanary, Reqable, ProxyPin...)

  مثال:
  vtpatcher -i app.apk -c certificate.pem


❖  فلاج Flutter (لتطبيقات فلاتر):
────────────────────────
  -f  ➜  تفعيل Flutter SSL Bypass

  مثال:
  vtpatcher -i flutter_app.apk -f -c cert.pem


❖  فلاج Pairip (لتطبيقات بايرب المحمية):
────────────────────────
  -p  ➜  تخطي حماية Pairip SSL (يشتغل في VM/Multi-App فقط بدون توقيع)

  مثال:
  vtpatcher -i pairip_app.apk -p -c cert.pem


❖  فلاج Hook CoreX (مع Pairip):
────────────────────────
  -x  ➜  حقن CoreX Hook (يدعم arm64 فقط)

  مثال:
  vtpatcher -i pairip_app.apk -p -x -c cert.pem


❖  فلاج AES Logs (لحقن سجلات AES):
────────────────────────
  -A  ➜  حقن AES Logs (لتسجيل المفاتيح)
  -A2 ➜  حقن Algorithm Hook (طريقة أخرى)
  -s  ➜  وضع AES.smali في DEX منفصل

  مثال:
  vtpatcher -i app.apk -A
  vtpatcher -i app.apk -A2
  vtpatcher -i app.apk -A -s


❖  فلاج إزالة الإعلانات:
────────────────────────
  -rmads  ➜  إزالة جميع الإعلانات

  مثال:
  vtpatcher -i app.apk -rmads


❖  فلاج تزوير معلومات الجهاز:
────────────────────────
  -r  ➜  تزوير جميع معلومات الجهاز (الموديل، الشركة، ID، IMEI، MAC)

  مثال:
  vtpatcher -i app.apk -r


❖  فلاج Android ID:
────────────────────────
  -D ID ➜  تغيير Android ID بـ 16 رقم

  مثال:
  vtpatcher -i app.apk -r -D 7e9f51f096bd5c83
  vtpatcher -i app.apk -D 7e9f51f096bd5c83


❖  فلاج تزوير حزمة التطبيق (Spoof Package):
────────────────────────
  -pkg  ➜  تزوير اسم الحزمة لتفادي كشف التعديل

  مثال:
  vtpatcher -i app.apk -pkg


❖  فلاج كسر الشراء (Purchase Bypass):
────────────────────────
  -P  ➜  تفعيل جميع طرق كسر الشراء والدفع

  مثال:
  vtpatcher -i app.apk -P


❖  فلاج تخطي تصوير الشاشة:
────────────────────────
  -rmss  ➜  إزالة منع تصوير الشاشة

  مثال:
  vtpatcher -i app.apk -rmss


❖  فلاج إزالة USB Debugging:
────────────────────────
  -rmusb ➜  إزالة فحص USB Debugging

  مثال:
  vtpatcher -i app.apk -rmusb


❖  فلاج تعديل Telegram:
────────────────────────
  -t  ➜  تفعيل جميع باتشات تليجرام (مكافحة حذف، بريميم، حفظ وسائط، DNS)

  مثال:
  vtpatcher -i Telegram.apk -t


❖  فلاج Pine Hook:
────────────────────────
  -pine  ➜  تفعيل Pine Hook
  -l  ➜  إضافة Xposed/LSP Modules

  مثال:
  vtpatcher -i app.apk -pine -l module1.apk module2.apk


❖  فلاج APKEditor:
────────────────────────
  -a  ➜  استخدام APKEditor بدلاً من APKTool (أسرع وأفضل للـ Patcing)

  مثال:
  vtpatcher -i app.apk -a


❖  فلاج الإموليتور:
────────────────────────
  -e  ➜  إذا كنت تستخدم إموليتور على الكمبيوتر

  مثال:
  vtpatcher -i app.apk -e -c cert.pem


❖  فلاج عدم التوقيع:
────────────────────────
  -u  ➜  إبقاء APK بدون توقيع

  مثال:
  vtpatcher -i app.apk -u


❖  فلاج دمج الملفات:
────────────────────────
  -m  ➜  دمج ملفات .apks / .xapk / .apkm إلى .apk

  مثال:
  vtpatcher -m app.apks


❖  فلاج تخطي باتش معين:
────────────────────────
  -skip  ➜  تخطي باتش معين (مثلاً getAcceptedIssuers)

  مثال:
  vtpatcher -i app.apk -skip getAcceptedIssuers


❖  فلاج عرض الشكر:
────────────────────────
  -C  ➜  عرض جميع المطورين المشاركين في الأداة


❖  فلاج المساعدة:
────────────────────────
  -h  ➜  عرض المساعدة
  -O  ➜  عرض باقي الفلاجات والأمثلة
